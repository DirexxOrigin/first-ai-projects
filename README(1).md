# First AI Projects

Two small web tools, built in one afternoon while exploring Claude (Anthropic).

## Files

- **`session-ampel.html`** – Rule-of-thumb indicator for Anthropic's confirmed peak usage hours (weekdays 3–9 PM CEST), plus a manual usage score for the current session.
- **`gedankensammler.html`** – Freeform note-taking tool with AI-assisted summary of the underlying thread of thought.

## Usage

Both files are plain HTML/CSS/JS with no build step. Just open them in a browser (double-click), or host them via GitHub Pages.

Learning projects only — no claim to completeness or production readiness.
